# HBM's Nuclear Tech Mod for Minecraft 1.21.1

An unofficial modern community-driven port of the legendary HBM's Nuclear Tech Mod, bringing its industrial machinery, material processing, fluids, radiation mechanics, power systems, foundry systems, protective equipment, nuclear technology, and experimental weapon systems to Minecraft 1.21.1 on NeoForge.

> Current version: **0.0.4-A**
>
> Status: **Early Alpha**

## Important Disclaimer

This project is currently in **Early Alpha**.

A significant part of the original mod has to be rewritten or adapted for modern Minecraft, NeoForge, modern rendering, networking, data-driven recipes, and world systems.

- **Survival Ready?**  
  Partially. Early-game and some industrial progression is playable, but large parts of the original progression are still being ported.

- **Recipe Viewers**  
  **JEI is highly recommended**, especially for custom Anvil, Chemical Plant, Foundry, and machine recipes.

- **Compatibility**  
  Existing worlds may occasionally require migration between early alpha versions while core systems are still being developed.

- **Experimental Content**  
  Some systems, including Fat Man, missiles, and satellites, are still incomplete or WIP.

- **Fat Man**  
  Fat Man currently uses visual explosion effects only. Full terrain destruction, radiation, and complete nuclear weapon behavior are not implemented yet.

- **Bugs**  
  Visual issues, missing recipes, incomplete mechanics, or crashes may still occur. Please report problems through GitHub Issues.
