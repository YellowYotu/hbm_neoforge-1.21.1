HBM NTM pre-fluids content pass

Added original-material support and currently feasible recipes for Press and Assembly Machine.
Added missing classic overworld ores using the original HBM default attempt counts and vein sizes, with vertical ranges adapted to Minecraft 1.21.1 and stone-only replacement.

Stamp Book: original HBM has eight printing metadata variants but no normal crafting recipe in the current official source. This port keeps one book item with eight selectable printing modes; right-click cycles the selected part. No invented survival recipe was added.

Soldering Station: the exact original machine construction recipe requires a cast steel plate. Cast Steel Plate is now present as a material, but its original production chain depends on metallurgy/casting systems not yet ported. The previous non-original Assembly Machine recipe for the Soldering Station was removed from the Assembly recipe index.

Electricity: the currently usable HE cable + battery socket network remains a compatibility implementation, not the full original NTM power-network subsystem.
